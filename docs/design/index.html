Smelt / UI direction

Direction chosen: dense industrial. Graphite surfaces, one orange accent, IBM Plex Sans Condensed for reading and IBM Plex Mono for anything a machine produced. State is carried by words, never by colour. This page is a design reference; the sample content shows layout and is not product code.

Approval card

User's job
Judge one action an agent wants to take, with enough context to say yes or no from a notification.
One action
Allow once. Decline is deliberately a text link, far from the thumb's resting place, so the two are never confused.

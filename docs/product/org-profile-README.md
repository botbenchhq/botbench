**Put your coding agents to work. Together.**

Botbench is a workbench on your Mac for the coding agents you already use, and a coordination layer between developers who each run their own.

- **The workbench.** Hand a task to Claude Code, walk away, and come back to a branch with its diff, your repository's checks and, if you choose, another vendor's review. You accept or reject it. Botbench never merges.
- **The coordination layer.** When a teammate's Botbench works the same GitHub repository, you see each other's open pull requests, are warned when they change the same files as yours, can claim an issue so only one of you starts it, and can check two changes together before either is merged. There is no shared server: the repository is the meeting point.

**Status.** Early, open source (Apache 2.0), macOS only, built from source. Paired workbenches exchange owner-approved questions and answers in a first form, tested with two installations on one Mac. More of the coordination layer is planned, not built.
